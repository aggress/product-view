# Product-View

## A web page to view product images where mousing over an image smoothly zooms in whilst reducing the size of the neighbours

1. Create a web page only using html, css and javascript, no external libraries or packages
2. The web page displays a grid of 20 x 20 10px wide white circles with 5px gap between each circle
3. The background of the web page is black
3. The circles are all images as pngs
4. When moving the mouse over a circle, scale the size of that circle to 20px smoothly whilst reducing the size of the neighbours smoothly
5. The effect needs to be smooth, likely with a number of different sized images of each circle
6. When I approve of the approach generate the code and any assets and check into the git repository in the folder
